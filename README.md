Mystery Message

Mystery Message is a full-stack web application built with Next.js that enables users to send and receive anonymous messages securely. Each user gets a unique shareable link through which others can send messages without revealing their identity.

Features
Secure user authentication using NextAuth
Anonymous message sending system
User dashboard to view received messages
Unique shareable profile links
Message deletion functionality
Modern server-side rendered architecture using Next.js App Router
Modular and reusable UI components
Tech Stack
Frontend: Next.js, React, Tailwind CSS
Backend: Next.js API Routes
Database: MongoDB with Mongoose
Authentication: NextAuth.js
Validation: Zod
Language: TypeScript
